# 专注城市建造（离线版）· Focus City Builder Extension

版本：v1.0.0 ｜ 类型：浏览器插件（Chrome / Edge，Manifest V3）

「专注清单」系列的城市建造版，玩法参考 SleepTown：专注学习的时间就是施工进度，
一座座建成各国各城市的著名建筑，攒出一座自己的城市。

## 功能

- 世界地标图鉴：30 座著名建筑、21 个国家、24 座城市（故宫、长城、东方明珠、东京晴空塔、
  埃菲尔铁塔、大本钟、伦敦眼、自由女神像、悉尼歌剧院、泰姬陵、吉萨金字塔、圣家堂……）
- 累计施工：一座建筑需 45–300 分钟专注建成，可跨多轮累积进度；施工中建筑从地基往上长
- 城市等级：启程小镇 → 成长城镇 → 繁华城市 → 国际都市 → 世界名城，等级解锁更宏伟的地标
- 深度专注黑名单：施工期间打开黑名单网站，本轮作废（已累积进度不清零）
- 工具栏倒计时角标、我的城市天际线、城市数据与施工记录、JSON 备份

## 隐私

完全离线：数据只保存在浏览器本地，不上传任何服务器。
无弹窗：点工具栏图标直接打开完整标签页。

## 安装

1. 下载或克隆本仓库到一个固定文件夹
2. Chrome 打开 `chrome://extensions`（Edge：`edge://extensions`）
3. 打开「开发者模式」
4. 点「加载已解压的扩展程序」，选择本文件夹

详细说明见 `安装说明.txt`。
